# 🛒 Marketplace Luiz

## Sobre o Projeto

O Marketplace Luiz é um projeto desenvolvido com HTML, CSS e JavaScript com o objetivo de simular a interface de um marketplace moderno.

O sistema possui estrutura preparada para catálogo de produtos, busca, menu responsivo, carrinho de compras e banners promocionais, servindo como prática dos conceitos fundamentais de desenvolvimento Front-end.

---

## Objetivos

- Praticar HTML5 semântico.
- Desenvolver interfaces responsivas.
- Aplicar conceitos de CSS moderno.
- Implementar interações com JavaScript.
- Construir um projeto para portfólio profissional.
